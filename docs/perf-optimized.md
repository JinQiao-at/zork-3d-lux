## 优化内容

**RoomShell 材质池化**（`demo/src/scene/RoomShell.tsx` 重写）：
- 74 个逐 mesh 内联 `meshStandardMaterial` → 模块级共享常量池 `MAT`（**唯一材质 30 个**，-59%）
- 通过 `material={MAT.x}` 属性传入——R3F 不会 dispose 外部材质，**zone 切换零重建**
- 绘制参数逐字保留（颜色/roughness/emissive/metalness/透明度），渲染表现不变
- 范围仅 RoomShell 纯装饰件；Props/AssetModel（可交互件有逐件高亮）不动
